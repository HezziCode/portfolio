## 🌟 Highlights & Features

- **High-Contrast Editorial & Neobrutalist UI:** Clean, tactile aesthetic inspired by modern engineering leaders like Linear, Vercel, and Supabase.
- **Embedded Story Video:** Native HTML5 video player and interactive modal showcase introducing the engineer behind the code without heavy initial page payloads.
- **Production Architecture Case Studies:** In-depth breakdown of production systems including:
  - **Al-Rafai Clinic:** 24/7 AI voice & chat patient booking with live calendar sync.
  - **WhatsApp AI Agent CLI:** Autonomous terminal automation with OpenAI Agent SDK & async webhooks.
  - **CogniClose:** Managed outbound pipeline and B2B research engine.
- **Automated Discovery Scheduling:** Direct 1:1 consultation scheduling powered by Cal.com API integration.
- **Resend Contact Pipeline:** Type-safe API route with Zod schema validation and automated notification delivery.
- **Exit-Intent Conversion Modal:** Non-intrusive desktop exit-intent capture with session cooldowns and fast discovery triggers.
- **Search Engine Optimization (SEO 10/10):**
  - Full Google Rich Snippets JSON-LD schema (`Person`, `WebSite`, `ProfilePage`).
  - Dynamic `sitemap.xml` and crawler-friendly `robots.txt`.
  - OpenGraph & Twitter preview cards for WhatsApp, LinkedIn, and X.
  - 100% semantic HTML and responsive viewport scaling.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/HezziCode/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory:
```env
# Cal.com Integration
CAL_API_KEY=your_cal_api_key
NEXT_PUBLIC_CAL_USERNAME=your_username
NEXT_PUBLIC_CAL_LINK=https://cal.com/your_username/30min
CAL_EVENT_TYPE_ID=your_event_id

# Contact & Inquiries
RESEND_API_KEY=your_resend_api_key
CONTACT_TO_EMAIL=your_email@gmail.com
NEXT_PUBLIC_SITE_URL=https://huzaifasys.com
```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
